# Alternative Target Structure Evidence Manifest

> **Public release note.** Some files in this repository were edited before publication: local absolute paths were made repo-relative, a machine hostname was removed, and material that is not redistributed here was taken out. Every SHA-256 recorded in this folder, including `SHA256SUMS`, was recomputed against the published files, so the hashes verify what is here rather than the internal working copy. No result, pose, score, table or log value was changed.


API-shaped payloads and generated notes preserved for the human SERT (SLC6A4) and μ-opioid receptor (OPRM1) structure feasibility audit.

The API payload bytes and checksums are preserved, but no request, response-header, or transport log was archived. Their `200` statuses and common fetch time below are **locally recorded metadata, not independently verified fetch proof**. Generated-file times were not recorded and must not be inferred from that common timestamp.

Five files that were once part of this package have been **withdrawn and removed**: four notes named `primary-excerpt-*` and `oprm1-human-mouse-alignment.txt`. The `primary-excerpt-*` notes were investigator-written summaries, not verbatim primary-literature excerpts or saved DOI responses; they contained unsupported assertions and two carried incorrect citation DOIs. The alignment file was internally contradictory. None of their claims are used anywhere in this repository. The table below records what they were so the provenance failure stays visible. The package contains no coordinate/mmCIF files, maps, article full text, full UniProt records, or saved RCSB search requests/results.
